The navigable page; its results are the same fragment R-49 answers, included rather than copied. **Exactly the accepted bounded filters (N-63), and nothing else is queryable.** There is no payload search, no message search, no global free-text box, no sort expression, no export flag and no mutation field — because an append-only table that grows forever cannot serve a free-text query within N-21's bound, and offering one would be offering a query that gets slower every day until it stops working. The action filter is a **prefix**, which is an index range. `%council%` would be a scan of every row that has ever been written, so the label says prefix and the backend treats it as one. **No CSRF token.** This is a `GET` read; N-17 applies to cookie-authenticated mutations, and a token on a read would imply this form changes something. **The browser validates nothing.** An invalid capability, source, UUID or instant is submitted and refused by N-63 server-side, with the accepted refusal. Filtering the choices here is a courtesy that keeps a reader from typing a value the server would reject; it is not the check, and no value is silently dropped on either side. **HTMX is optional.** `hx-get` on the form swaps the results container in place; without JavaScript the same form is an ordinary `GET` to `/v1/audit` that renders the whole page.
