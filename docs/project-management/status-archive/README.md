`../status.md` current-state entry point. Snapshot files stay beside
`status.md`, rather than inside this directory, so their original relative links
continue to resolve.

Archived status is evidence and must not be silently rewritten. Corrections
belong in a new current record or a dated erratum that identifies the affected
archive. Moving material here does not change a decision, finding, gate,
authority or disposition.
