# Handover archive

This directory indexes consumed, superseded and historical material removed
from the concise `../Handover information` active-assignment entry point.
Snapshot files stay beside that entry point, rather than inside this directory,
so their original relative links continue to resolve.

Archived handover text is evidence and must not be silently rewritten.
Corrections belong in a new active record or a dated erratum that identifies
the affected archive. Moving material here does not create, extend or revive an
assignment or operational authority.
