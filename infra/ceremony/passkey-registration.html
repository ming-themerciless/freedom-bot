Register an emergency passkey

This page is temporary. It exists only to create the emergency passkeys for the Server Administrator, and it is removed once they are enrolled.

Check the address bar before you continue. The passkey you create is permanently tied to the exact web address shown there. If it does not read the address you were told to open, stop — a passkey made at the wrong address will look fine and will never let you in.

Your device will be asked to store the passkey on itself (a "discoverable" credential, which is what a passkey normally is). That is required: when you sign in, the site deliberately tells the browser nothing about which accounts or credentials exist, so your device has to be able to offer the passkey without a hint. An authenticator that refuses to store it cannot be used for emergency access.

  1. Type your name, so the passkey is labelled in your phone or password manager.
  2. Press the button and follow your device's prompt (Touch ID, Windows Hello, a security key, or your password manager).
  3. Copy the block of text that appears and paste it into the command you were given.

What this page does and does not do. It runs entirely in your browser. It sends nothing anywhere — no network request of any kind. It stores nothing. Closing the page discards everything, and you would simply run it again.
