# T-L12 corpus for XD (proposal §5.15, XD-10). Hand-encoded from the manuals,
# not from objdump output or the committed listing, and written before the
# first build of rp11-launch existed.
#
#   SDM = Intel SDM Vol. 2, 325383-093US.  APM = AMD APM Vol. 3, 24594 r3.20.
#
# Line kinds (fields separated by " | "):
#   + <row id> | <hex bytes> | <expected canonical decode> | <citation>
#       decoded alone at address 0x401000; the whole vector must be one
#       instruction of exactly that row.
#   - <class> | <hex bytes> | <what it is> | <citation>
#       decoded alone at 0x401000; must fail with that XD-5 class
#       (b unsupported encoding, c undecoded byte).
#   s <class> | <_start hex> | <rp11_main hex> | <what it is>
#       a two-function .text at 0x401000 with .rodata at 0x402000..0x402040;
#       decode_text must report that class (or "pass" for none).
#
# Canonical form: Intel operand order (destination first); registers by
# their Intel names; mN[...] an N-bit memory operand; iN:0x.. an N-bit
# immediate as encoded; relN:0x.. the absolute direct target.
